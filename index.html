Library

Kept in Documents/Downbeat. Clear forgets the results; your folders stay.
Removes only the files Downbeat saved itself in Documents/Downbeat: settings, the track library, the Music / SFX library, leftover temp files. Nothing else in that folder is ever touched.

Updates

Asked once at the first start. When on, Downbeat asks GitHub once every three days for the number of the latest release. Nothing about you is sent, and nothing is installed: you download an update yourself.

Diagnostics

Runs every feature on the selected clip, including real test cuts. Use disposable material.
